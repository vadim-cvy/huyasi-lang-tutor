# Base agent instructions

## Linting and Formatting

Do not raise linting or formatting issues in code reviews. Linting and formatting are enforced automatically by ESLint and Prettier in CI; those checks must still pass before merging.

## Additional Instructions

Don't forget to check the following `*.md` files:

- `README.md`: General instructions for the whole monorepo.
- `AGENTS.*.md` files for specific instructions:
  - `AGENTS.frontend.md`: Instructions for the frontend agent.
