# Base UI components for web-client apps and libs

## Components provided by this package:

### Components you'll likely use in your apps and libs the most frequently:

- `Page`
- `Content404` _(you can use it inside `Page` for 404 pages)_
- `Button`

### Other components:

- `Footer` _(already included in `Page`)_
- `Header` _(already included in `Page`)_
- `Sidebar` _(already included in `Page`)_
- `LogoTitle` _(already included in `Header`)_
- `NavPrimary` _(already included in `Sidebar` and `Footer`)_
